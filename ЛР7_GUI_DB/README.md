Фермерские рынки
Приложение для поиска фермерских рынков по городу, штату или ZIP-коду с фильтрацией по расстоянию, отзывами и рейтингами.

Запуск без Python

1. Скачайте `FarmersMarkets.exe` по ссылке: https://drive.google.com/drive/folders/1GHNYM0wT-RTtfngbGqeI2hxlSvibA50v?hl=ru
2. Скачайте в папку с `FarmersMarkets.exe` файл `.env.example`. Замените пароль на свой.
3. Запустите `FarmersMarkets.exe`.

Запуск с Python

1. Клонируйте репозиторий ЛР7_GUI_DB
